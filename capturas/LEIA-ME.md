# Capturas de referência

Coloque aqui as capturas de tela usadas como referência visual. Qualquer formato de imagem serve (PNG, JPG, WEBP).

Nomes sugeridos, para facilitar a comparação tela a tela:

- `01-shell.png`: janela principal (menus, toolbar, árvore, abas, painel de informações, status)
- `02-arvore-conexoes.png`: árvore de conexões expandida
- `03-nova-conexao.png`: diálogo de conexão (General/SSH/SSL/Advanced)
- `07-editor-sql.png`: editor SQL com resultado
- `08-resultados.png`: grid de resultados
- `09-dados-tabela.png`: dados de tabela em edição
- `10-designer-tabela.png`: designer de tabela (Fields/Indexes/Foreign Keys...)
- demais telas: use o número UI-xx da especificação seguido de um nome curto

Inclua a resolução e a escala do Windows no nome quando puder (ex.: `01-shell-1920x1080-100.png`).

> As imagens são só para consulta interna e não vão para o Git, porque o `.gitignore` desta pasta as exclui. Nenhum ícone ou asset de terceiros será copiado para o Atlas.
